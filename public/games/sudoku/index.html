놀이 방법

넣기
칸을 고르고 아래 숫자를 누릅니다. 같은 줄·칸·상자에 이미 있는 숫자는 눌리지 않습니다.
X 표시
X 표시를 켜고 숫자를 누르면 "이 칸엔 이 숫자가 아니다"라고 표시해 둡니다. 다시 누르면 풀립니다.
후보 보기
빈칸에 작게 보이는 숫자가 지금 넣을 수 있는 후보입니다. X 로 지운 숫자는 사라집니다.
난이도
1~10레벨. 숫자가 적게 주어질수록, 또 어려운 풀이법이 필요할수록 레벨이 올라갑니다. 10레벨은 단순 소거만으로는 풀리지 않습니다.
시간
첫 숫자를 넣을 때부터 잽니다. 레벨별 최고 기록이 이 브라우저에 남습니다.
다 풀면
폭죽이 터지고 같은 레벨의 새 문제로 바로 넘어갑니다. 멈추고 싶으면 다른 레벨을 누르세요.
자판
화살표 이동 · 1~9 넣기 · 0/Backspace 지우기 · X 표시 모드 · P 멈춤 · N 새 문제 · Ctrl+Z 되돌리기
